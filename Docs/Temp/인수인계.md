## 2. 사용자 작업 : 캐릭터 휘두름 · 적중 소리 교체

캐릭터들의 휘두름 소리와 타격음이 심심해서 새 음원을 받으려 한다. 음원 검색 · 선택 · 다운로드는 사용자가 직접 하고(사운드 컨벤션), Claude 는 검색어 · 넣는 곳 · 라이선스 확인을 돕는다.

### 넣는 곳

- 휘두름(시전) 소리 : 각 캐릭터 액션 데이터의 **동작(Steps)** 마다 `Swing Sound`. 동작에서 처음 판정할 때 한 번, 적이 없어도 난다
- 적중 소리 : 각 캐릭터 액션 데이터의 `Hit Sound`. 적에게 대미지를 준 판정마다 한 번 난다
- 소리 묶음은 목록에 여러 개를 넣으면 무작위로 골라 반복감이 줄어든다. 볼륨은 묶음마다 정한다
- 여러 소리를 겹쳐 고를 때는 확인용 `SoundLayerPreview` (아무 오브젝트에 붙이고 플레이 중 P 키) 로 미리 들어 본다
- 공통 소리(패링 · 완벽 회피 · 대시 등)는 효과음 설정 에셋 `Assets/Datas/Audio/SfxSettings.asset`. 순간마다 `Extra Layers` 로 겹을 더할 수 있다

### 이미 임포트한 팩에서 먼저 들어 볼 후보 (이름만 보고 고름, 미청취)

| 용도 | 위치 (`Assets/Imports/Sounds/Magic Pig Games (Infinity PBR)/Audio/Battle Sound Library/Battle/...`) |
|---|---|
| 휘두름 (바람 가르는 소리) | `Miss/Miss_Hit_1` ~ `5` |
| 칼 베기 적중 | `Sword/Sword_On_Flesh/Impact`, `Sword/Sword_On_Flesh/Flesh` |
| 주먹 · 발 적중 | `Fist/Fist On Flesh` |
| 금속 충돌 (패링) | `Sword/Sword_On_Metal/Impact`, `Sword/Sword_On_Metal/Metal` |
| 저음 폭발 겹 | `../Magic (Mono)/<속성>/Explosion` |

### 새로 찾을 때 검색어 (영어 사이트 기준)

**휘두름 소리**

| 캐릭터 · 무기 | 검색어 | 뜻 |
|---|---|---|
| 검방 (한손검) | `sword swing`, `sword whoosh`, `blade swish`, `fast whoosh` | 가볍고 빠른 칼 휘두름 |
| 대검 | `heavy sword swing`, `greatsword whoosh`, `heavy whoosh`, `low whoosh` | 무겁고 낮게 바람 가르는 소리 |
| 격투가 | `punch whoosh`, `kick whoosh`, `martial arts whoosh`, `cloth whoosh` | 주먹 · 발 · 옷자락 휘두름 |
| 스킬 · 필살기 강조 | `energy whoosh`, `magic swing`, `anime whoosh` | 기술 시전 느낌을 더하는 겹 |

**적중 소리**

| 캐릭터 · 무기 | 검색어 | 뜻 |
|---|---|---|
| 검방 (한손검) | `sword slash hit`, `blade cut`, `slash impact` | 베는 타격 |
| 대검 | `heavy sword hit`, `heavy slash impact`, `crushing hit` | 묵직하게 찍는 타격 |
| 격투가 | `punch impact`, `kick hit`, `body punch`, `heavy punch` | 주먹 · 발 타격 |
| 강타 · 공통 강조 겹 | `anime impact`, `cinematic hit`, `impact boom`, `hit stinger` | 과장된 타격감, 저음 터짐 |

**패링 (앞서 정리한 것)** : `sword clash`, `blade clash`, `sword parry`, `metal impact heavy`, `metal clang`, `metal ring`, `shing`, `anime sword clash`, `cinematic sword impact`, `impact boom`

- 함께 넣으면 좋은 말 : `short` (짧은 길이), `dry` (울림이 적음), `heavy` (묵직함), `punchy` (단단하게 치고 빠짐)
- 젠존제 같은 타격음은 대개 여러 겹이다 (본체 타격 + 저음 터짐 + 금속 · 스파크 꼬리). 겹이 섞인 음원을 고르거나, 효과음을 여러 소리로 나눠 겹쳐 쓴다
    - 액션의 휘두름 · 적중 소리는 지금 한 겹(묶음 하나)만 낸다. 액션 소리도 겹이 필요하면 공통 소리처럼 추가 겹을 넣는 작업을 제안한다

### 사이트와 라이선스

- Freesound : 라이선스 필터에서 CC0 선택. 사이트 전체가 CC0 은 아니므로 파일마다 개별 페이지의 라이선스를 확인한다
- Pixabay Sound Effects : 자체 라이선스(Pixabay Content License). 소리 개별 페이지의 라이선스 표시와 사이트 아래쪽 License · Terms 를 확인한다. 출처 표기는 필요 없다고 안내하지만, 가공 없이 원본 그대로 재배포 · 판매는 안 된다
- Unity Asset Store : 구매 · 무료 에셋 라이선스 (Standard EULA)
- 쓰기로 정한 파일은 이름 · 업로더 · 페이지 주소 · 라이선스를 `Docs/Planning/Used Assets.md` 에 기록한다 (기획서 규칙 : 파일별 라이선스 확인)

### 임포트 설정 (짧은 효과음)

- `Load Type` : `Decompress On Load` (첫 재생이 늦지 않게)
- 앞부분에 무음이 있으면 소리가 늦게 들린다. Inspector 파형 미리보기로 확인하고, 있으면 편집 프로그램으로 잘라 쓴다
