## 3. 남은 작업 순서

1. ~~이펙트 풀 + 적중 이펙트~~ (끝)
2. 동작 이펙트 이벤트 → 확인 : 이벤트마다 위치 · 회전 · 크기, 캐릭터 따라감, 한 동작 여러 번, 교체 중 풀 깨지지 않음
    - 풀에 부모(따라갈 캐릭터) 지원을 더해야 한다. 부모가 꺼지면 회수하고 풀 아래로 되돌린 뒤 위치 · 회전 · 크기 초기화 (계층구조 컨벤션 `풀링 대상의 계층과 반환`)
3. 패링 이펙트 · 처치 디졸브 → 확인 : 연속 패링 포함 매번, 디졸브 후 비활성화
    - 디졸브 셰이더 : DeadleafGames `DissolveShader` (URP Lit, Alpha Clip). 프로퍼티 `_Base_Tex` · `_BaseColor` · `_Normal_Tex` · `_Emission_Tex` · `_DissolveAmount` 등. 진행 값 방향(0 이 멀쩡한지)은 데모 Material 로 확인할 것
    - 적 두 종류 모두 지금 URP Lit Material (보스 PolyartDefault, 골렘 Golem Earth)
4. 콤보 선택 화면 효과 → 확인 : 서서히 켜짐 · 꺼짐(실제 시간), 꺼진 동안 왜곡 Renderer 꺼짐
    - PC 설정은 Opaque Texture 켜짐, 모바일 설정은 꺼짐
5. 완벽 회피 잔상 (연속 잔상)
6. 그로기 무지개 막대
7. (사용자) 임시 표시 교체
8. 기술 문서(BattleFeedback · PlayerAttack · PlayerStructure · BattleHud · EnemyCommon) · 콘솔 확인 → PR
