## AI가 틀렸거나 직접 고친 사례

- 상황: 데이터 폴더에서 이펙트를 모으는 에디터 버튼 작성
- AI 결과: 모든 속성을 끝까지 따라가게 만들어, 행동 그래프의 참조 순환에서 무한 반복이 일어나 에디터가 멈춤. 11-21 lilToon 사례와 같은 실수를 반복함
- 고친 내용: 탐색 범위를 데이터 폴더로 좁히고, 참조형 속성 안으로는 들어가지 않게 수정함

- 상황: 타이틀 네온 글자 발광이 Game 화면에서 보이지 않음
- AI 결과: 처음에 HDR 색 설정을 원인으로 잘못 짚음
- 고친 내용: 스크린샷으로 Overlay Canvas 가 HDR 색을 잘라 낸다는 것을 확인함. 사용자가 카메라 Canvas + Bloom 방식으로 결정함

- 상황: 사선 9-slice 막대가 0 근처에서 칸 밖으로 나감
- AI 결과: 여백 조정 → 채움 영역 마스크 → 가리개 구조 순으로 원인을 세 번 잘못 짚음. 스크린샷을 보고 "해결됐다"고 잘못 보고한 적도 있음
- 고친 내용: 사용자 제안대로 판넬의 막대 칸 안쪽만 따낸 마스크 이미지를 만들어 해결함

- 상황: 에너지 막대 색 이미지를 코드 자동 탐색에서 Inspector 칸으로 바꿈
- AI 결과: 막대 Prefab 안에 같은 이름(`Fill`)의 오브젝트가 둘이라는 점을 안내하지 않아, 대기 칸 하나가 다른 막대에 연결됨
- 고친 내용: 씬 파일을 추적해 잘못 연결된 칸을 찾고, 사용자가 다시 연결함
