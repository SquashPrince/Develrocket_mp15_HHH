# AI 활용 기록 (agentlog) 템플릿

> AI(Claude · Codex)를 어떻게 썼고 시간이 얼마나 걸렸는지 기록하는 문서의 템플릿이다. <br>
> 작업 일지는 "무엇을 했는지", agentlog는 "AI를 어떻게 썼고 얼마나 걸렸는지"를 적는다. 같은 내용을 두 곳에 반복해 적지 않는다.

## 사용 기준
> 작성 위치는 `Docs/AgentLogs/<GitHub 계정명>/YYYY-MM-DD.md` 이며, 하루에 파일 하나를 쓰고 같은 날의 기록은 각 표에 행을 추가한다. <br>
> 해당하지 않는 섹션은 `없음` 으로 적는다.

- 기록 시점
    - 사용자 검수에서 작업이 승인됐을 때
    - `[작업 시간]` 훅 알림을 받고 사용자에게 중단 여부를 확인했을 때
    - Codex 에 작업 지시서를 전달했을 때, Codex 결과를 받았을 때
    - 사용자가 기록을 요청할 때
- 시각은 명령으로 확인한다. 추측해서 적지 않는다.
- 사용자가 작업을 중단했었다고 답한 공백은 소요 시간에서 빼고, 비고에 적는다.
- `AI 미사용 시 예상` 은 사용자가 답한 값만 적는다. 답이 없으면 `미기록` 으로 둔다.
- 담당은 `Claude`, `Codex`, `사용자` 중에서 적는다. 함께 한 작업은 `Claude + 사용자` 처럼 적는다.
