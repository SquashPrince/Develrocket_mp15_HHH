# Project : Hollow Horizon Hunter

## 스토리

어느 날 공허(**Hollow**) 속에서 나타난 몬스터들에 의해 폐허가 된 도시.
가까스로 살아남은 그들은 과거의 도시(**Horizon**)를 되찾기 위해 몬스터를 처치하러(**Hunter**) 다니고 있다.

## 게임 특징

- **패링으로 받아치기** : 적의 노란 예고에 교체 키를 누르면, 들어오는 캐릭터가 적 앞으로 순간 이동해 공격을 막아 냅니다
- **태그 액션** : 스킬을 쓰다 교체해도, 나간 캐릭터가 기술을 끝까지 쓰고 퇴장합니다
- **콤보 스킬 연계** : 그로기 상태의 적에게 강타를 맞히면, 캐릭터를 골라 이어받는 연계 공격이 이어집니다
- **완벽 회피** : 적의 공격을 아슬아슬하게 피하면 적만 느려지고, 그 사이 회피 반격을 할 수 있습니다
- **캐릭터 3명** : 방패와 검의 기사, 대검의 전사, 맨손의 격투가
- **구역 진행** : 일반 적 웨이브를 정리하고 보스를 처치하면 결과 등급이 나옵니다

## 실행 방법

1. 아래 **Assets** 에서 `HollowHorizonHunter_v1.0.0_Windows.zip` 을 받습니다
2. 원하는 폴더에 압축을 풉니다
3. `Hollow Horizon Hunter.exe` 를 실행합니다

- 지원 환경 : Windows 64bit
- 최고 기록과 설정은 `%USERPROFILE%\AppData\LocalLow\mp15 Develrocket KJJ\Hollow Horizon Hunter\` 에 저장됩니다. 기록을 지우려면 이 폴더의 `best_record.json` 을 삭제하세요
