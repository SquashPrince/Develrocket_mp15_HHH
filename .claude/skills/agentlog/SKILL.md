# AI 활용 기록 (agentlog) 작성

> 이 스킬은 절차와 멘트 규격만 정의한다. 규칙의 원본은 아래 문서이며, 내용을 이 파일에 복사하지 않는다.

## 참조 문서 (필요 섹션만 읽는다)

- 기록 시점 · 작성 위치 · 기록 원칙 · 양식 : `Docs/Templates/AgentLog.md`
- 작성자 폴더 이름 : GitHub 로그인 계정명 (`gh api user --jq .login` 으로 확인한다. 실패하면 경로를 추측하지 않고 사용자에게 보고한다)

## 사용 시점

- 사용자 검수에서 작업이 승인됐을 때 : 작업 시간 행을 추가한다. (멘트 ②)
- `[작업 시간]` 훅 알림을 받았을 때 : 진행 중인 작업보다 먼저 중단 여부를 묻는다. (멘트 ①)
- Codex 에 지시서를 전달하거나 결과를 받았을 때 : Codex 작업 행을 추가 · 갱신한다. (멘트 ②)
- 사용자가 기록을 요청할 때 : 요청한 섹션을 작성한다. (멘트 ②)

## 절차

1. 참조 문서를 읽는다.
2. 현재 날짜와 시각을 명령으로 확인한다. 추측하지 않는다.
3. 오늘 파일이 있으면 읽고, 없으면 양식으로 새로 만든다.
4. 대화 · Issue · PR · Commit 기록에서 추가할 행을 채운다. 기록에서 확인하지 못한 값은 사용자에게 묻거나 양식의 기준(`미기록` 등)을 따른다.
5. 추가할 내용을 사용자에게 보여주고 승인을 받는다. 사용자 답변으로 채운 부분은 따로 표시한다.
6. 승인 후 파일에 반영하고 결과를 보고한다. (멘트 ③)
7. 이미 기록된 행은 사용자 요청 없이 수정하지 않는다.

## 멘트 규격

① 작업 시간 알림 응답

```
[agentlog] 마지막 입력 후 N분이 지났습니다. (HH:MM → HH:MM)
- 진행 중이던 작업 : <작업, 없으면 "없음">
그동안 작업을 중단하셨나요? (중단했다면 이 시간은 소요 시간에서 뺍니다)
```

② 기록 전 안내

```
## agentlog 추가 : YYYY-MM-DD
- 저장 위치 : `Docs/AgentLogs/<작성자>/YYYY-MM-DD.md`
- 근거 기록 : <참고한 대화 · Issue · PR · Commit>

(추가할 행)

이 내용으로 기록할까요?
```

③ 기록 후 보고

```
agentlog 저장 : Docs/AgentLogs/<작성자>/YYYY-MM-DD.md
- 추가 : <섹션별 추가 행 수>
```
